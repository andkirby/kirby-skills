# Existing app evidence

The product is used by engineers working with technical documents.

Current areas:
- Projects
- Documents
- Recent
- Search
- Reviews
- Settings

Observed/common workflows from project notes:
- reopen a document worked on recently
- locate a document by project or search
- review proposed document changes
- understand whether a review needs action

Unknown:
- whether "Reviews" is important enough to be a top-level area
- whether users think primarily in projects or personal work queues

Constraint:
- keep the first release small
