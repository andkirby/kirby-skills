# Product Intent fixture

Actors: engineers working with technical documents.

Primary intentions:
1. Resume recent work quickly.
2. Find a known or vaguely remembered document.
3. Understand what requires attention.
4. Review proposed changes in context.
5. Manage work within a project.

MVP capabilities:
- projects
- document organization and access
- recent/resumable work
- search
- review changes and act on a review
- status/attention visibility

Open uncertainty:
- whether the attention/review queue should be a cross-project destination or only contextual.
