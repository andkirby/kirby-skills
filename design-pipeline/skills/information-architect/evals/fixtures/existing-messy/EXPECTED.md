# Expected behavior

The run should identify at least these tensions:
- Tasks appears both global and project-local without an explicit ownership model.
- Documents/Files may be duplicate terminology for the same concept.
- Recent/Favorites may be lenses or work-entry mechanisms rather than peer product domains.
- Settings is utility navigation mixed with work destinations.
- Reviews needs object/context modeling before deciding whether global access is justified.

The run must reconstruct and explain the current IA before proposing a replacement. It must not merely reorder the sidebar.
